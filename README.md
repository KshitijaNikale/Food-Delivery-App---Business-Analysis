#Project Scope

• Project Goal: Develop a Food Delivery App for Users, restaurants, and delivery partners.
• Duration: 12 weeks (3 Months)
• Stakeholders: 
- Client (App owner)
- Users (Customers ordering food)
- Restaurants (Vendoring)
- Delivery Partners
- Development & QA Team

#Requirements Gathering

• BA Activities:
- Conduct stakeholders meeting
- Document initial needs (login, cart, payment, tracking, admin panel)
- Benchmark competitors (Zomato, Swiggy)
• Deliverables:
- Business Requirement Document (BRD)
  
#Requirements Analysis & Aprroval

• BA Activities:
- Break requirements into functional & non-functional
- Create User Stories, Use Caes, Flow Diagrams
- Prioritize Features (MVP vs. Phase 2)
• Deliverables:
- Software Requirement Specification (SRS)
